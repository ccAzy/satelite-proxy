## 原始稿（纯黑底）提取配方

与霓虹稿（`icon-neon/README.md`）同款**鲁棒圆角矩形拟合**，且更简单——
本次辉光**没有溢出到瓦片外**（fg bbox 与中带直边完全重合），无辉光窗口特判：

1. 阈值 maxchannel>6，自边框洪泛得背景，取反=瓦片前景（洞已补）；
2. 中带行/列取直边中位数：L122 R1132 T122 B1121（1011×1000）；
3. 四角弧点逐角圆拟合：r≈272.5–275.1，共享 274（残差 <7px）；
4. 4x 超采样圆角矩形掩膜、外扩 1.5px 吞掉边缘抗锯齿，裁切；
5. 1019×1008 居中垫方 → 876px @86% 居中 1024 画布。
